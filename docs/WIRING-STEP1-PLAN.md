## 2. 配置层：`src/config.js`

```js
export const WIRING = {
  maxM: 1e12,             // ★ 拉表结论：纯安全阀（表 A ✓），不调手感 ✗
  costC0: 85,             // ★ 拉表结论：20 条边 ≈ 6h（表 C ✓）
  costGamma: 1.5,         // ★ 多项式 ⇒ 天然安全 ✓
  refund: 0.5,            // 拆线返还 50% ✓
  sWindowSec: 60,         // 波动窗口 ✓
  edgeWeight: 0.35,       // 本步固定权重（不做权重升级 ✓⇒ 下一步再说 ✓）
  weightCap: 0.6,         // 单边上限 ✓
  nodeCaps: { particle: 3, matter: 2, zpe: 2, ... },  // 每节点入边容量 ✓
  tutorial: [             // 免费边（**不计入**成本曲线计数 ✓）
    { from: "matter",  to: "particle" },
    { from: "particle", to: "matter" },
  ],
};
```

新增函数（全部小、纯、可单测 ✓）：

| 函数 | 作用 | 约束 |
|---|---|---|
| `edgeCost(state)` | 下一条边的物质价：`costC0 · (已付费边数+1)^costGamma ÷ 物质产出`（以秒表示 ✓） | 多项式 ✓ |
| `edgeCapacityOf(zone, state)` | 该节点入边容量（`nodeCaps` + 未来升级 ✓） | — |
| `networkMultiplier(state)` | `M = min(1/(1 − S), maxM)` ✓ | **S 走 `computeS`** ✓ |
| `previewEdge(state, from, to)` | 返回 `{ ok, dS, dM, paybackSec, reason }` ✓（**预演** ✓ 规格 §10.2） | 与真接后的实测误差 **< 1%** ✓（断言 ✓） |
| `sVolatility(state)` | 近 `sWindowSec` 秒的 S 波动：`{ min, max, span }` ✓ | 只读窗口 ✓ |

### ★ 关键实现细节：`M` 与 `S` 是**互相依赖**的（必须解一个不动点 ✗）

```
M 的落点在环上（ZPE 产出 ✓）⇒ 接上后 S 会变 ✓
而 M 又由 S 决定 ⇒ 需要自洽：  S = S₀ + α·log10(M)   且   M = 1/(1 − S)
⇒ 一维不动点，5~10 步迭代即可收敛 ✓（必须断言迭代收敛 ✓）
⇒ **不许**用"上一步的 S"糊过去 ✗（那会让预演说谎 ✗）
```
