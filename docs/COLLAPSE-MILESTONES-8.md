## 1. 逐条的公式与安全检验

### ① 10 粒子 + 10 物质开局 ✓
```
落点：doBigCrunch 末尾
    state.resources.particle = max(particle, 10)
    state.resources.matter   = max(matter,   10)
安全：常数 ✓ 不进任何环 ✓
断言：坍缩后两者都 ≥ 10 ✓；未达成里程碑时不变 ✓
```

### ② 改进计数频率 ✓（需你确认"改进"的意图 ✗）
```
现状：countFreqAddTerm = 1 + 0.05 × 等级（仿射 ✓）
提案 A（稳妥 ✓）：每级系数 0.05 → 0.10（等于把这条升级的价值翻倍 ✓）
提案 B（改工作方式 ✗）：从仿射改成 1 + 0.05·等级^1.5（多项式 ✓ 后期更陡 ✓）
安全：两者都是**多项式** ✓（A 线性 ✓ B 1.5 次 ✓）⇒ 判据通过 ✓
⚠️ 但它是 `b`/ZPE 倍率链的成员 ⇒ 改动会**影响破∞时长** ✗ ⇒ 需重标定 ✓
```

### ③ 100:1 → 50:1 ✓
```
落点：conversion() 的 threshold 上乘 0.5
   ⇒ 粒子产出翻倍（同样的熵给两倍粒子 ✓）
安全：常数 ✓ 不进环 ✓
断言：达成后 threshold 恰好是达成前的一半 ✓
```

### ④ 4 量子开局 ✓
```
落点：doBigCrunch 末尾  state.quantum = max(quantum, 4)
⚠️ 注意：`quantum` 与 `quantumPairs` 是**派生关系**（每对给 perPair 个 ✓）
   ⇒ 直接设 quantum 会与 pairs 轻微不同步 ✗ ⇒ **建议同时不动 pairs** ✓（只作为"开局赠礼"✓）
   若你想严格自洽 ⇒ 改成 `pairs += 2`（给 1 对 ✓）✓ —— 两句我都能实现 ✓ 你选一句 ✓
安全：常数 ✓
```

### ⑤ 相变仪随持有 IP 增幅（倍增而减缓）✓ —— 这条的"减缓"正好就是对数 ✓
```
transmuterRateMult = 1 + c × log10(1 + 无限点)
   IP=1e6  ⇒ ×2.6（c=0.5）     ← 前期猛 ✓
   IP=1e12 ⇒ ×7.0              ← 每翻十倍只多 +0.5 ✗ = "倍增而减缓" ✓✓
   IP=1e50 ⇒ ×26
   IP=1e308⇒ ×155（仍需硬上限 ✓，建议封顶 ×100 ✓）
安全：对数 ⇒ 判据安全 ✓✓
断言：单调 ✓；IP 翻十倍时增量恒定（= c ✓）；封顶生效 ✓
```

### ⑥ 每对量子 +1 ✓
```
落点：quantumPerPair() 的返回值 + 1（2 → 3 ✓；与 pairBoost 叠加时 3 → 4 ✓）
安全：这是**每对的离散量** ✓ ⇒ 不随任何连续量缩放 ✓ ⇒ 判据无关 ✓
⚠️ 但它进 ZPE/跨度链（q ↑）⇒ 会**加快**破∞ ✗ ⇒ 重标定 ✓
```

### ⑦ 量子获得公式重做（前期更多、后期更难）✓
```
现状：第 n 对门槛 = 1e10 × 20^n
提案：底数 1e10 → **1e8**（前 1~2 对来得更早 ✓）
      步长 20 → **22**（后期更难 ✓）
   n=0:  1e8   （原 1e10 ⇒ 早 2 个数量级 ✓ "前期更多" ✓）
   n=5:  1e8×22^5 ≈ 5.2e14（原 1e10×20^5 = 3.2e16 ⇒ 早 ~1.8 个数量级 ✓）
   n=15: 1e8×22^15 ≈ 1e28（原 1e10×20^15 ≈ 3.3e29 ⇒ 略早 ✓）
安全：几何阶梯 ✓（指数在 n 上 ⇒ 但 n（对数）随 ZPE 只按对数增长 ⇒ 复合仍是多项式 ✓）✓
⚠️ 数值需你拍板（1e8/×22 vs 其它组合 ✓）
```

### ⑧ 游玩时间的全局加成 ✓
```
globalMultiplier ×= 1 + c × log10(1 + t_分钟)      （c ≈ 0.1）
   t=1 分   ⇒ ×1.03     ｜ t=60 分 ⇒ ×1.18 ｜ t=10 小时 ⇒ ×1.28
安全：对数 ✓（对时间多项式/次线性 ✓）⇒ 判据安全 ✓✓
⚠️ 它进的是**全局加成** ⇒ 按项目红线，只有"真·全局"的东西能进 ✓ —— 这条**确实是全局时间加成** ✓
   ⇒ 合规 ✓（但它是"全局面板"的成员 ⇒ 必须登记在 globalMultiplierParts ✓）
断言：t 翻十倍 ⇒ 增量恒定（= c ✓）；t=0 ⇒ ×1 ✓
```
