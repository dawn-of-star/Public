## 2. 图的定义

### 2.1 节点（沿用现有的加成位置系统 ✓）

```
节点 = **乘区** ✓（`ZONES` / `ZONE_OF` 已有的那套 ✓）
   例如：物质 / 粒子 / 熵 / ZPE / 暗能量 / 量子 / 梦想 / 无限点 …
   每个节点有：产出 `p_n`（公式不变 ✓）、以及一个「接线容量」`cap_n`（能接几条边 ✓，可升级）
⚠️ 节点集合**不新增**：就用现有乘区 ✓（这正是我们独有的资产 ✓）
```

### 2.2 边（这就是新动词 ✓）

```
一条边 e：`from → to`，带权重 `w_e`（≥0）
效果：`p_to ×= (1 + w_e)` ✓ —— 即"A 的产出加强 B" ✓

关键：**默认边已经接好** ✓（就是现在的直线链 ✓）
   ⇒ 空图 = 现在的游戏（逐位一致 ✓ 零回归 ✓）
   ⇒ 玩家新增的边是**跨链的横向连接** ✓（原本不存在的耦合 ✓）
```

### 2.3 环与 S（我们已有的判据 ✓）

```
图里出现**环**时（A→B→A ✓），产出会被自己放大 ✓
   放大系数（线性系统稳态）：`M = (I − A)^{-1}` 的谱半径 ≈ `1 / (1 − S)` ✓
   其中 `S = Σ log(mᵢ)/log(rᵢ)`（**复用 `computeS` ✓ 单一数据源 ✓**）

⇒ **S < 1 ⇔ 环收敛** ✓（数学上严格 ✓）；`S → 1` 时 `M → ∞` ✓
⇒ 这就是玩法：玩家的收益 = `M(S)` ✓，代价 = S 越靠近 1 越危险 ✗
```

## 3. 玩家做什么（无限阶段）

```
动词：**接线** ✓（买边）、**拆线** ✓（退边，返还部分物质 ✓）

1. 花**基本物质**买一条边 ✓（物质是唯一警戒值 ✓ ⇒ 它天然是"扩建预算"✓）
       cost(e) = c₀ · (已接边数 + 1)^γ        γ ≈ 1.5（多项式 ⇒ 安全 ✓）
2. UI **必须**在购买前显示这条边的**边际影响** ✓：
       ΔS（例如 "0.72 → 0.78" ✓）、ΔM（收益倍率 ✓）、Δ物质产出（回本时间 ✓）
3. 边有**容量**约束：每个节点 `cap_n` 条入边 ✓ ⇒ 不能把所有东西都接到一个节点上 ✓
   ⇒ 玩家要做**结构选择**（接在哪、接几条、留多大余量 ✓）
4. **拆线**：返还 50% 物质 ✓，S 立刻回落 ✓（这是"见好就收"的机制 ✓）
```

**这一段替换掉的东西** ✓：
```
现在是：破∞后挂机攒 IP（15 分钟糊过去 ✗）
改成：破∞后开始接线（用物质扩建网络 ✓）⇒ 进度来自**网络质量** ✓ 而不是"攒够数字"✗
```

## 4. 玩家做什么（永恒阶段）

```
永恒不再是"IP ≥ 1e308.25"这一个数字 ✗，而是**网络满足一组约束** ✓（挑战型门槛 ✓）：

   永恒门槛 = 同时满足：
      ① 至少存在 1 个环 ✓（真的接出了自我加速 ✓）
      ② 该环的 S ∈ [S_lo, S_hi]（例如 [0.5, 0.95] ✓ —— 太保守不行 ✗ 太贪也不行 ✗）
      ③ 环上至少覆盖 3 个不同乘区 ✓（结构要求 ✓）
      ④ 至少 1 条边是**跨链**的 ✓（不是原来就有的 ✓）

   永恒的奖励 = **规则修改权** ✓（不是乘数 ✗）：
      · 允许"守恒再分配"：把一个节点的产出份额**拆**下来挪给另一个 ✓（Σ 份额 = 1 ✓）
      · 允许"二次接线"：把边接到边上 ✓（形成超边 ✓）
      · 提高某些节点的 `cap_n` ✓
      · 解锁"约束试炼"：用特定约束再通关一次，换一条新边类型 ✓
```

## 5. 数值与安全（判据统一在此 ✓）

```
判据（前几轮反复验证 ✓）：
   任何"数量 → 加成"若是**指数** ⇒ 有限时间爆炸 ✗；只有**多项式**（线性/开根）安全 ✓

本机制的落点：
   · 边的权重 `w_e`：**加法区**（`1 + w` ✓ 多项式 ✓），且 `w_e` 单条有上限 ✓
   · 边的价格：多项式（`n^γ` ✓）⇒ 不会自持爆炸 ✓
   · 环的放大 `M(S) = 1/(1−S)`：在 S→1 处发散 ✗ ⇒ **必须硬上限** ✓（`M ≤ M_max` ✓）
       并且 S 的每一项仍由 `computeS` 提供 ✓ ⇒ 不存在"另一套 S" ✓
   · 守恒再分配：`Σ 份额 = 1` ⇒ **总量守恒** ⇒ 天然无爆炸 ✓✓

⚠️ 唯一红线（沿用）：
   图上的边**不许**接进「全局加成」❌ —— 否则重现"环增益 Q²、物质一次跳无限"的旧 bug ✗
```

## 10. 教学（**已定：送 1~2 条免费边当教学** ✓）

### 10.1 要教的四件事（按顺序 ✓）

```

```

### 10.3 第一分钟的流程（脚本化 ✓，只走一次 ✓）

```
[破∞ 的同一屏]
```

## 11. 数学拉表结论（2025，用来定数 ✓）与**对前文的四条修正** ✗→✓

> 用户定调：这种数一律**拉表定** ✓（本节的三个表都由脚本算出 ✓）
> 模型：网络收益 `M = min(1/(1−S), M_max)`；单条边价格 `c₀·(n+1)^γ`；物质收入 ∝ `M` ✓

### 表 A：`M = 1/(1−S)` 与各 `M_max` 的封顶点

| S | M = 1/(1−S) | M_max=1e3 封顶于 | M_max=1e6 封顶于 | M_max=1e12 封顶于 |
|---|---|---|---|---|
| 0.9 | 10 | S > 0.999 | S > 0.999999 | S > 0.999999999999 |
| 0.99 | 100 | 同上 | 同上 | 同上 |
| 0.999 | 1e3 | 同上 | 同上 | 同上 |
| 0.999999 | 1e6 | 同上 | 同上 | 同上 |

⇒ **结论**：取 `1e6` 与取 `1e12`，**玩法上完全没区别** ✗ ⇒ `M_max` 是**安全阀**（防数值爆炸 ✓），
**不是**手感旋钮 ✗。

**✗→✓ 修正 1（改 §5 与 §9 问题 5）**：
```
M_max = **1e12**（纯安全阀 ✓）
手感旋钮是**边的成本曲线**（见表 C ✓），不要再指望 M_max 调玩法 ✗
```

### 表 B：最优停点与"为什么真正的风险是漂移"

| λ（成本弹性/收益弹性） | 最优 S_opt = 1 − 1/λ | 余量 |
|---|---|---|
| 10 | 0.9000 | 0.100 |
| 100 | 0.9900 | 0.010 |
| 300 | 0.9967 | 0.0033 |
| 1000 | 0.9990 | 0.0010 |

⇒ **结论**：无论 λ 多大，玩家的**自然最优**都是**贴到红线** ✗ ⇒ "贪"不是设计出来的 ✗，
是数学必然 ✓。⇒ **真正的张力来自 `S` 会自己漂** ✓✓：
```
游戏在跑 ⇒ 量子 / 暗能量 / 环收益都在变 ⇒ S 会漂
   你接的时候 S = 0.996，跑到一半可能 1.001 ⇒ 崩落 ✗
⇒ **"该留多少余量" = "S 的波动幅度"** ✓✓（这才是本机制的技术点 ✓）
```

**✗→✓ 修正 2（改 §6 UI 方案）**：
```
UI **必须显示 S 的近期波动范围**（例如近 60 秒的 ±幅度 ✓），只显当前值**不够** ✗
   例： S = 0.996 ▓▓▓▓▓▓▓▓░ 1.000 ｜ 近 60 秒波动 ±0.004 ⇒ **余量不足** ⚠️
⇒ 没有它，"留余量"就退化成盲猜 ⇒ 机制立刻不好玩 ✗
```

**✗→✓ 修正 3（改 §3 的崩落语义与 §5）**：
```
崩落判定 = **漂移越线** ✓（不是"贴线惩罚"✗）
   ⇒ 玩家会为"跑着跑着越线"负责 ✓，而不是因为"接得太满"被罚 ✗
   ⇒ 于是"留余量"成为**真正的技术** ✓（配合修正 2 的波动显示 ✓）
```

### 表 C：时长预算（**唯一的节奏旋钮** ✓）

设：单条边价格 `c₀·(n+1)^γ`、物质收入 ∝ `M` ⇒ 每接一条边的耗时 = 价格 / 收入 ✓

| 目标时长（固定 20 条边，γ = 1.5） | 需要的 c₀ |
|---|---|
| 1 h | 1.42e1 |
| 3 h | 4.26e1 |
| **6 h（当前目标 ✓）** | **8.52e1** |
| 12 h | 1.70e2 |

⇒ **结论**：时长由「单条边价格 ÷ 物质收入」决定 ✓，旋钮是 `c₀`（整体快慢 ✓）与 `γ`（尾段陡度 ✓）；
且它是**多项式**（`n^1.5`）⇒ 天然安全 ✓（不像指数会爆 ✗）。
