## 1. R 到底是什么（一句话）

`R` = **指数成长速率**（数量级/秒）。它给物质一个 `∝ M` 的项：

```
dM/dt += M · ln10 · R        ⇒  log10(M) 随时间以斜率 R 线性增长
```

**没有它，物质到不了 1e308**：基础成长是 `M'' ∝ log(M)`（多项式），
乘任何倍率只能 `log10(M) ∝ 2·log10(t) + 常数(C)` —— 只加常数，改不了形状（实测 perPair=200 也走不到顶）。

## 3. 三个候选（都用暗能量）

| 候选 | 形式 | 优点 | 风险 |
|---|---|---|---|
| **D1 暗能量升级（可重复）** | 花**暗能量**买等级 → 抬 R 上限（等价于把「速率解放」从 ∞ 搬到 DE） | 改动最小、玩家已熟悉"可重复升级" | 需要定"每级 +多少 / 涨价多少"，且 DE 收入曲线要能撑住 |
| **D2 暗能量里程碑（阈值）** | 暗能量跨过 `10^k` → 给一档 R（离散台阶） | 与既有 ZPE/DE 里程碑风格一致；**不可刷**、天然有节奏 | 台阶之间的空窗期要设计（否则又是"等"） |
| **D3 暗能量连续式** | `R = a·log10(DE) + b`（把现在的"量子饱和式"输入换成 DE） | 连续、平滑；数学上最接近现状，迁移最省 | DE 是**被 ZPE 喂**的，链变成"ZPE → DE → R"，要确认链条顺序合意 |

> 我倾向 **D2 + D1 组合**：里程碑给"台阶"（节奏感），升级给"微调"（可玩性）。
> 而 D3 与 D1 在数学上可互相模拟，选哪个取决于"你想让玩家**点按钮**还是**等阈值**"。

### 5.2 ⚠️ 数学前提（否则方案会在"到顶时间"上翻车）

**多项式增长永远到不了 1e308**：若 `物质 ∝ t^p`（任何固定 p），则 `log10(物质) ≈ p·log10(t)`，
要 308 阶 ⇒ `log10(t) ≈ 308/p`：p=6 → **1e51 秒**，p=18 → **1e17 秒** ✗ 都荒谬。
只有 `log10(物质) ∝ c·t`（时间里**指数**）⇒ 308 阶只需 `308/c` 秒 ✓

⇒ **"暗能量跨到 1e50"必须实现为"暗能量在时间里指数增长"**，不能只是被 ZPE 线性推。
`dm5` 正好是这个自反馈的种子 ✓ 于是节奏旋钮非常干净：**到顶时间 = 50 / a**（a = DE 的指数速率）。
对比 R 需要 0.147 阶/秒（跨 283 阶），新方案只需跨 50 阶 ⇒ 对速率常数的要求宽松 **5.7 倍** ✓

### 9.5 ⑤ 安全性：幂落在**环外** ⇒ S 判据不受影响（这一条解释"旧问题"）

- **旧问题**（项目踩过）：把量子加成放进**全局加成**时，熵与物质**两端各乘一次** ⇒ 环增益变成 `Q²` ⇒ 物质一次跳到无限 ✗（所以量子被改成只作用在熵产出这一条单线上）。
- **本方案为什么安全**：`物质 ∝ DE^k` 的幂作用在**环的输出侧** —— 环是「熵阱 ↔ ZPE」（traps → ZPE → multiplier → traps），而 DE 是 ZPE 的**下游**（相变仪 ZPE→DE），物质是 DE 的**下游** ⇒ 幂不参与环增益 ✓
- **前提条件（必须守住）**：**不要把 k 或 DE 的倍率接回 ZPE / 熵阱 / 全局加成**，否则旧问题立刻重现 ⇒ 用断言守住（`de-span-lab --check` 的第 6 条 + 落地时补"k 不进环"的静态检查）。
